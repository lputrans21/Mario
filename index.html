📊 INTEGRASI GOOGLE SPREADSHEET

PENGATURAN GOOGLE SPREADSHEET

Skor akhir siswa otomatis terkirim dan tersimpan langsung ke baris Google Spreadsheet guru secara realtime.

📌 Cara Menghubungkan Google Sheet Guru:
1. Buka file Google Spreadsheet baru di akun belajar.id Anda.
2. Klik menu Ekstensi > Apps Script, buat fungsi doPost(e) untuk menyimpan baris data siswa.
3. Klik Terapkan (Deploy) > Penerapan Baru (New deployment) > Aplikasi Web (Web app), pilih Siapa saja (Anyone).
4. Salin URL Web App dan tempel di kotak atas, lalu klik Simpan.
5. Setiap siswa yang menyelesaikan game langsung otomatis tercatat di Spreadsheet guru!
